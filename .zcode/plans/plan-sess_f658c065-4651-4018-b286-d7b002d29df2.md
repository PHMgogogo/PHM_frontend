## 目标

参照 API.md 第 9 个接口 `POST /api/display`（图表数据查询/展示代理），为 `DashboardContainer.vue` 接入真实的数据展示流程。

**数据链路（全部走现有 `/api` 代理 → `http://192.168.31.13:8001`）：**
1. 选定单机 → `getMappings({ aircraftNumber })` → 得到 `ConfigDataMapping[]`
2. 选定一条 mapping → 用 `mapping.csvTableName` 作为 display 的 `data` 字段；用 `mapping.mappingId` 调 `getCsvOverview(mappingId)` → 得到 `dataColumns`（即 display 的可选 `columns`）
3. 用户在 UI 选定 `columns` / `type` / `limit` → 调 `display({ data, columns, limit, type })` → 得到 series-style 响应 → 转成 ECharts option → 注入 DashboardContainer 画布

## 架构决策

**配置面板与画布职责分离**（遵循用户设计意图）：
- `MonitorView.vue` 作为容器，采用 `flex` 横向布局：左侧 `DashboardContainer`（画布）+ 右侧 **可收起侧栏**（数据源配置面板，新组件）
- `DashboardContainer` 保持纯粹的"画布"职责，GridLayout 内部容器宽度恒定为 12 列，不受配置面板开合影响
- 配置面板的展开/收起由 `MonitorView` 层用一个 ref（如 `sidebarCollapsed`）控制，通过 flex 宽度过渡，不触及 DashboardContainer 内部的栅格计算

**画布初始态**：移除 mock 注入，初始为空，显示 DashboardContainer 自有的"暂无图表"空状态作为引导。

**3D 点云**：新增 `echarts-gl` 依赖，`POINT_CLOUD_3D` 用 `scatter3D` 渲染真 3D。

## 实现步骤

### 1. 新增依赖

`package.json` → `dependencies` 增加 `"echarts-gl": "^3.9.0"`（与 echarts 6 兼容）。需 `npm install`。

### 2. 新建 `src/api/display.ts`（新文件）

遵循 `aircraft.ts` / `csv.ts` 的 `createClient({ baseURL: '/api' })` 模式：

```ts
import { createClient } from './client'

const client = createClient({ baseURL: '/api' })

/** display 接口的 type 枚举 */
export const DISPLAY_TYPE = {
  SINGLE_TIMESERIES_2D: 'SINGLE_TIMESERIES_2D',
  MULTI_TIMESERIES_2D: 'MULTI_TIMESERIES_2D',
  MAPPING_2D: 'MAPPING_2D',
  POINT_CLOUD_3D: 'POINT_CLOUD_3D',
} as const

export interface DisplayDimension { name: string; unit: string }
export interface DisplaySeries { parameter: string; color?: string; data: (number|string)[][] }
export interface DisplayRequest {
  data: string
  columns: string[]
  limit?: number
  type: typeof DISPLAY_TYPE[keyof typeof DISPLAY_TYPE]
}
export interface DisplayResponse {
  dimensions: DisplayDimension[]
  parameter: string[]
  data: DisplaySeries[]
}

export function queryDisplay(req: DisplayRequest) {
  return client.post<DisplayResponse>('/display', req)
}
```

### 3. 新建 `src/components/dashboard/DisplayOptionBuilder.js`（新文件）

纯函数模块：把 `DisplayResponse` 按 `type` 转成 ECharts option。复用 `chart-configs.js` 里的 `COMMON_CHART_CONFIG`、`DEFAULT_COLOR_PALETTE`。

- `SINGLE_TIMESERIES_2D` / `MULTI_TIMESERIES_2D` → `line` series，x 轴取 `dimensions[0]`，每条 series 一个 parameter
- `MAPPING_2D` → `scatter` series（2D，x/y）
- `POINT_CLOUD_3D` → `scatter3D` series，需 `echarts-gl`（在 ChartWidget 注册）
- 统一用 `dimensions[].name` 作为轴标签，`series.color` 优先用响应里返回的，否则取调色板

导出：`buildDisplayOption(displayType, response, size)` → 返回 ECharts option。

同时导出一个 `getRequiredColumnCount(type)` 辅助函数：返回每种 type 需要的列数（2/2+/2/3），用于在 UI 侧做 columns 多选的校验提示（type 决定可选列数约束）。

### 4. 新建 `src/components/dashboard/DataSourcePanel.vue`（新文件）

右侧可收起侧栏。`<script setup>` 内承载完整的查询链路状态：

**Props**: `aircraftNumber: string`（可选；若提供则自动拉取 mappings）

**内部 reactive state**:
```
mappings: ConfigDataMapping[]      // getMappings 结果
mappingsLoading: boolean
selectedMappingId: number | null   // 当前选中的 mapping
columns: string[]                  // getCsvOverview 结果（候选列）
columnsLoading: boolean
selectedColumns: string[]          // 用户勾选的列（多选）
selectedType: DISPLAY_TYPE         // 用户选定的图表类型
limit: number                      // 用户输入的 limit，默认 0
selectedSize: 'small'|'medium'|'large'  // 复用 monitorDashboardConfig.sizes
loading: boolean                   // display 查询 loading
```

**交互链路（watch / async）**:
1. `watch(aircraftNumber)` 变化 → `getMappings({ aircraftNumber })` → 填充 mappings，清空下游 columns/selectedColumns
2. `watch(selectedMappingId)` 变化 → 找到对应 mapping，`getCsvOverview(mappingId)` → 填充候选 columns
3. `selectedType` 变化 → 根据 `getRequiredColumnCount(type)` 提示并约束 `selectedColumns` 选择数（如 MAPPING_2D 需恰好 2 列，POINT_CLOUD_3D 需恰好 3 列）

**UI 模板**（el-collapse 三组）:
- **折叠/展开按钮**：顶部一个图标按钮，点击 emit `toggle` 事件给父级（MonitorView 控制侧栏宽度）
- **数据源组**：单机输入框（el-input，绑定 aircraftNumber，可手动输入/修改）→ el-select(mappings)
- **图表配置组**：el-select(type) + el-select(multiple, columns) + el-input-number(limit) + el-select(size)
- **操作组**：「查询并添加图表」按钮（校验列数后 emit `add-chart` 事件，payload 为 `{ data, columns, limit, type, size }`）

**Emits**:
- `add-chart` → `{ data: csvTableName, columns, limit, type, size }`（父级负责真正调 display + 注入画布）
- `toggle` → 通知父级切换侧栏收起

> 注：是否把 display 调用放在 DataSourcePanel 还是 MonitorView？**放在 MonitorView**，让 DataSourcePanel 只产出"查询参数"，display 调用 + 转 option + 注入画布都在 MonitorView 完成。这样组件职责单一，便于复用与测试。

### 5. 修改 `src/components/dashboard/ChartWidget.vue`

为支持 `POINT_CLOUD_3D`：
- 新增 import `Scatter3DChart` from `echarts-gl/charts` 和 `Grid3DComponent`、`VisualMapComponent`、`DatasetComponent` from `echarts-gl/components`（或对应 core 路径）
- 在 `use([...])` 中注册这些模块
- 其余逻辑（option watch、resize 等）不变，3D option 由 DisplayOptionBuilder 产出，ChartWidget 透传即可

> 注意：echarts-gl 的 component 需从 `echarts-gl` 包导入并注册；`Grid3D`/`VisualMap` 需要在 option 里配置。具体导入路径在实现时按 echarts-gl 文档确认（`import 'echarts-gl'` 整体注册是最稳妥的写法）。

const sidebarCollapsed = ref(false)

### 7. 修改 `src/components/dashboard/DashboardContainer.vue`

仅做一处新增（不破坏现有逻辑）：

- 该方法用 `findEmptySpace` 找空位，构造 `{ i: generateId(), x, y, w: sizeConfig.w, h: sizeConfig.h, option, title, type: 'display', category: '', static: false }` push 到 `layout`
- 其余（emit ITEM_ADDED、autoSave）与 `addDashboardItem` 一致

不修改现有 `addDashboardItem`、控制面板、GridLayout 逻辑——保持向后兼容。

### 8. 单机来源

MonitorView 当前无 aircraftNumber 来源（不在 `/aircraft/:aircraftNumber` 路由下）。方案：
- DataSourcePanel 顶部放一个 **el-input 让用户手动输入 aircraftNumber**（如 "J-20A"），输入后触发 `getMappings`。
- 不强制接 router param 或 aircraftStore（避免侵入路由结构）。用户在输入框输入后即驱动整条链路。
- 这是最小侵入方案；后续若需从路由取，再扩展。
